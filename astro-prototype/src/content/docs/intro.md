Zero2Root connects structured learning paths, assessment tools, offensive-security methodology, AI security and independent research.

## How the platform is organised

- **Explore:** navigate the knowledge map, search all indexed destinations and inspect relationships between topics.
- **Tools & Automation:** open detailed practitioner guides with commands, interpretation, evidence practices and troubleshooting.
- **Workflows:** follow a controlled assessment lifecycle from authorisation to retesting.
- **Browse:** access the complete indexed library without relying on the visual map.

## About this prototype

This is an isolated Astro and Starlight implementation. The interactive explorer uses the existing Zero2Root content index. The ten Tools & Automation guides are rendered locally by Starlight; other destinations link to the current documentation preview until their content is migrated.

The prototype is not the production website and does not replace the existing MkDocs deployment.
