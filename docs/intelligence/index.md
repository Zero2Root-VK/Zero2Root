# Vulnerability Intelligence

**Status: In development.**

The Intelligence area is planned to connect vulnerability records with the products, weaknesses, advisories and research around them.

## Planned coverage

- CVE records and affected products
- CWE weakness classifications
- GitHub Security Advisories
- CVSS severity and scoring context
- EPSS probability context where available
- Public exploit references and remediation guidance
- Relationships between vulnerabilities, products and weaknesses

## Data quality principles

Every record should retain its source, publication date and update context. Scores and exploit references should be presented with their provenance rather than treated as independently verified findings.

The searchable intelligence database and knowledge graph are not live yet. For now, use the existing [Vulnerability Assessment learning material](../level-1/03-vulnerability-assessment.md).
