# Learning paths

Build a structured cybersecurity foundation and progress toward advanced security engineering.

<div class="grid cards" markdown>

    Networking, operating systems and core security concepts.

    [Start Level 0](../level-0/index.md)

-   **Level 1 — Junior Pentester**

    Reconnaissance, scanning, OWASP and introductory exploitation.

    [Start Level 1](../level-1/index.md)

-   **Level 2 — Mid-Level Pentester**

    Advanced web, API, mobile and infrastructure testing.

    [Start Level 2](../level-2/index.md)

-   **Level 3 — Senior Pentester**

    Red team, cloud, exploit development and engagement management.

    [Start Level 3](../level-3/index.md)

-   **Level 4 — Lead / Architect**

    Program design, threat modeling, GRC and leadership.

    [Start Level 4](../level-4/index.md)

</div>
