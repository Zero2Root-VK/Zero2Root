# Security Research

Zero2Root Research is the home for original security analysis, responsible disclosures, technical write-ups and engineering notes.

## Research areas

- Vulnerability analysis and responsible disclosure
- CVE and GitHub Advisory research
- Web, API and infrastructure security
- Exploitability analysis and defensive implications
- Security engineering experiments

## Publication standards

Research entries should distinguish confirmed observations from hypotheses, include reproducible evidence where appropriate, identify affected versions and describe remediation.

The research library is being organized. Existing background and project information is available on the [About page](../about.md), and the [GitHub repository](https://github.com/Zero2Root-VK/Zero2Root) contains the open-source learning content.
