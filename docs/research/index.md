## Research areas

<div class="grid cards" markdown>

-   **Vulnerability analysis**

    Responsible disclosure, exploitability analysis and defensive implications.

-   **CVE and GitHub Advisory research**

    Vulnerability triage, affected-version analysis and advisory preparation.

-   **Application security**

    Web, API and mobile security research.

-   **Infrastructure security**

    Network, identity, cloud and configuration research.

-   **Exploitability analysis**

    Reproducible technical analysis, prerequisites and defensive implications.

-   **Security engineering**

    Experiments, tooling, automation and engineering notes.

</div>

## Publication standards

Research entries should distinguish confirmed observations from hypotheses, include reproducible evidence where appropriate, identify affected versions and describe remediation.

Existing background and project information is available on the [About page](../about.md), and the [GitHub repository](https://github.com/Zero2Root-VK/Zero2Root) contains the open-source learning content.
